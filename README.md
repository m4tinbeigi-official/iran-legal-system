| **شرکت‌ها، بورس و اسناد** | لایحه اصلاحی ۱۳۴۷، قانون جدید صدور چک (ماده ۲۳)، اسناد برات و سفته | محاکم حقوقی، اجرای ثبت، هیئت داوری بورس |

| **ثبت، املاک و مستغلات** | قانون الزام به ثبت رسمی اموال غیرمنقول (مصوب ۱۴۰۳)، روابط موجر و مستأجر | دفاتر اسناد رسمی، سامانه کاتب، دادگاه حقوقی |

| **مالیات و دارایی** | مواد ۱۰۵، ۱۳۱، ۱۶۹ مکرر مالیات‌های مستقیم، پایانه‌های فروشگاهی و مؤدیان | هیئت‌های حل اختلاف مالیاتی (ماده ۲۴۴) |
| **آرای وحدت رویه دیوان** | آرای ۷۳۳، ۸۱۱، ۸۵۰ (قیمت روز ملک)، ۸۰۵ (وجه التزام)، ۷۹۴ (ابطال سود بانکی) | تمامی شعب دیوان عالی و محاکم بدوی و تجدیدنظر |

## موتور دوگانه دادرسی (Dual-Engine Execution Framework)

هر موضوع ورودی، طبق گردش‌کار استاندارد دادگستری ایران ارزیابی می‌شود:

```
[ورودی: قرارداد، واقعه، ادعا، یا سناریوی اختلاف]
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│ ۱. توصیف و تکییف حقوقی (Legal Qualification)                │
│    - تطبیق با عناوین قانونی، تعیین مرجع صالح، کشف ماهیت عقد │
└────────────────────────┬────────────────────────────────────┘
                         │
         ┌───────────────┴───────────────┐
         ▼                               ▼
┌────────────────────────────────┐ ┌────────────────────────────────┐
│ ۲. لایحه دفاعیه وکیل مدافع      │ │ ۳. دادنامه و انشای رأی قاضی    │
│    - ایرادات شکلی ماده ۸۴      │ │    - گردش‌کار پرونده            │
│    - دفاعیات ماهوی و جرح ادله  │ │    - احراز ارکان مادی و روانی   │
│    - استناد به اصول و وحدت رویه │ │    - استناد به مواد صریح قانون │
│    - تقاضای رد دعوا یا برائت   │ │    - صدور قرار یا حکم ماهوی     │
└────────────────┬───────────────┘ └────────────────┬───────────────┘
                 │                                  │
                 └───────────────┬──────────────────┘
                                 ▼
┌─────────────────────────────────────────────────────────────┐
│ ۴. چک‌لیست امن‌سازی و اقدامات فوری (Actionable Safeguards)   │
│    - بازنویسی شروط مبهم، تضمین‌های ملکی/بانکی، کاهش ریسک   │
└─────────────────────────────────────────────────────────────┘
```

## نحوه استفاده و نصب

### ۱. استفاده به عنوان مهارت هرمس (Hermes Agent)

کپی کردن فایل‌ها در مسیر مهارت‌های هرمس:

```bash
mkdir -p ~/.hermes/skills/legal/iranian-legal-audit
cp -r skills/iranian-legal-audit/* ~/.hermes/skills/legal/iranian-legal-audit/
```

سپس در مکالمه هرمس فراخوانی می‌شود:

```
skill_view(name='iranian-legal-audit')
```

### ۲. اجرای ابزار خط فرمان (CLI Auditor)

اسکریپت پایتون بدون نیاز به کتابخانه جانبی برای غربالگری سریع مواد:

```bash
python3 scripts/audit_case.py "شکایت از پیج اینستاگرامی و کلاهبرداری اینترنتی با سیم‌کارت"
```

نمونه خروجی:
- استخراج کدهای مواد مرتبط (مواد ۱ تا ۱۸ جرایم رایانه‌ای، ماده ۱ تشدید، آیین دادرسی).
- ساختاربندی پیش‌نویس لایحه دفاعیه.
- تعیین استانداردهای فارنزیک مورد نیاز فتا.
